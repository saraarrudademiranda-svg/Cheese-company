# Excel Data Model – Cheese Price & Exchange Rate Analysis

## Project Overview

This Excel data model was developed as part of my college studies to practise data modelling, Excel calculations, automation and user interface design.

The project was based on a business scenario involving a cheese company that imports products from France and the Netherlands. The company needed a model to analyse how fluctuations in the Euro-to-Pound exchange rate could affect selling prices, sales volume and overall profit.

The model allows users to enter different exchange-rate values and adjust percentage rates to explore different scenarios and their potential impact on the business.

## Key Features

- Interactive dashboard
- Data input through an input box
- Adjustable percentage rates using buttons
- Automated calculations using Excel formulas and macros
- Exchange-rate fluctuation analysis
- Profit and sales calculations
- Pivot charts for analysing results
- Username and password access
- User-friendly navigation
- Ability to enter new values and analyse different scenarios
- What-If analysis
- Automated changes to calculations based on user inputs

## Development Process

The project was developed through several stages:

1. **Requirements analysis** – Identified the client's requirements and the purpose of the model.
2. **Planning** – Planned the model structure, functionality, interface and success criteria.
3. **Design** – Designed the spreadsheet structure, calculations, navigation and user interface.
4. **Development** – Implemented the calculations, macros, input functionality, dashboard and charts.
5. **Testing** – Tested different exchange-rate and percentage scenarios to check that the model produced the expected results.
6. **Documentation** – Documented the planning, development, testing and evaluation of the completed model.

## Learning Context

This was a college learning project created while developing my Excel and data-modelling skills.

I was provided with tutorials and demonstrations covering Excel data modelling, calculations and related techniques. I applied these techniques to develop the model and adapted them to meet the requirements of the given business scenario.

The user-interface form was initially created with assistance from a classmate, which helped me understand how to implement it within the model.

The project demonstrates my ability to learn new Excel techniques, apply them to a business scenario, modify and combine different features, and develop a functional model.
